CSS の使い方

src/saba.css を利用側 repository へ vendor し、取得元 commit SHA を記録します。latest URL への runtime 依存は使用しません。

<link rel="stylesheet" href="assets/vendor/saba.css">

<div class="saba-sheet">
  <header class="saba-site-header">...</header>
  <main>...</main>
  <footer class="saba-site-footer">...</footer>
</div>

利用可能な tokens、components、page profiles は design document を参照してください。
