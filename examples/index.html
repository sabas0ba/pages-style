sabas0ba / pages design

Checkpoint 1

Portfolio / Documentation / Application の 3 用途を同じ design token と component API で表現する静的サンプルです。

Portfolio 現行 sabas0ba/sabas0ba に近い card + dot grid 表現 Documentation 長文・code・navigation を重視した文書向け表現 Application panel / form control / workspace を使う Web アプリ向け表現

CSS の使い方

src/saba.css を利用側repositoryへvendorし、取得元commit SHAを記録します。latest URLへのruntime依存は使用しません。

<link rel="stylesheet" href="assets/vendor/saba.css">

<main class="saba-page">
  <article class="saba-card">...</article>
</main>

利用可能なtokens、components、page profilesはdesign documentを参照してください。
