再現可能な開発環境

Nix を単一情報源として、開発 shell、container image、WSL 環境を同じ package set から構成します。

設計原則
依存関係は固定し、開発環境の外部へ暗黙の状態を持ち込みません。

セットアップ

リポジトリを取得した後、開発 shell に入ります。

$ nix develop
$ scripts/check-env.sh
$ make check

構成

nix/packages.nix を tool list の単一情報源として扱い、Dockerfile へ package 名を重複して記述しません。

経路用途
nix develop対話的な開発
make checkローカルと CI の共通検査
変更後は make check を通し、Nix または container 関連の変更時は container 側も検証します。
